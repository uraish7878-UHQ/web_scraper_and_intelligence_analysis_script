# Bookstore Intelligence: Competitor Book Catalog Analysis

## Overview
This project collects book information from [Books to Scrape](https://books.toscrape.com/) and analyzes the catalog to support basic competitor and market research. The Python script scrapes book listings, cleans selected fields, prints summary insights, builds a budget-based book portfolio, and creates a star-rating distribution chart.

## Features
- Scrapes book listings from the Books to Scrape catalog.
- Extracts each book's title, price, star rating, stock availability, and product URL.
- Converts star ratings from words (One–Five) into integers (1–5).
- Saves the scraped data to `competitor_books.csv`.
- Reports the most expensive and cheapest books, average price, number of five-star books, and in-stock percentage.
- Lists the five highest-rated books, using price as a tie-breaker.
- Identifies the cheapest five-star book.
- Simulates a book-selection challenge with a £100 budget.
- Generates `rating_distribution.png`, a bar chart of the number of books at each rating.

## Project Files
- `web_scraper_and_intelligence_analysis_script.py` — main Python scraper and analysis script.
- `competitor_books.csv` — output dataset containing the scraped book records.
- `rating_distribution.png` — rating distribution chart generated by the script.

## Requirements
Python 3.9 or later is recommended. Install the required libraries:

```bash
pip install pandas matplotlib requests beautifulsoup4
```

## How to Run
1. Save the Python script in your working folder.
2. Open a terminal or command prompt in that folder.
3. Install the dependencies listed above.
4. Run:

```bash
python web_scraper_and_intelligence_analysis_script.py
```

By default, the script scrapes five catalog pages:

```python
df_data = scrape_books(max_pages=5, scrape_all=False)
```

To scrape all 50 catalog pages, change the call to:

```python
df_data = scrape_books(scrape_all=True)
```

The site must be reachable over the internet for scraping to work. The script includes a short delay between page requests.

## Dataset Columns
| Column | Description |

## Notes and Limitations
- This is a learning/research project using the Books to Scrape demonstration website, not a production retail data source.
- The script writes output files to the current working directory.
- The £100 challenge sorts books by rating (highest first) and price (lowest first), then adds books while the budget allows.
- The script assumes at least one five-star book exists when selecting the cheapest five-star book. If none exists, that analysis step will need an additional empty-result check.
- Use scraping responsibly and respect the target site's terms and access policies.
